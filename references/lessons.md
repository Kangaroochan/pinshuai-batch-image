# 出图经验记录（pinshuai-batch-image）

这里只记**出图这边**的经验：参考图选哪张、带整张截图还是裁图还是不带、配对、尺寸比例、模型和参数、中转站报错、耗时。提示词写法的经验记在写提示词那个 skill 自己的经验文件里（比如 圣诞珍珠画01 的 `references/lessons.md`），不记在这里。规则见 SKILL.md 的"同步经验"一节。每次配对出图前先读一遍。2026-10-31 改名：本 skill 原名 batch-product-render，圣诞珍珠画01 原名 batch-prompt-diversify；之前的出图文件夹和报告里还是旧名字。每条不超过 8 行，逐张明细留在出图文件夹的 report.md 里。

## 状态

- **待观察**：只在 1 批出图或 1 次反馈里见到，只作参考。
- **已确认**：在至少 2 批独立出图里见到同样的结果，或用户明确确认过。
- **已建议改规则**：已向用户提出具体的 SKILL.md 修改，等用户确认。
- **已写入规则**：用户同意后已写进 SKILL.md，注明日期和改了哪一节。
- **用户决定不改**：用户看过建议后决定保留现状，注明原因，不再重复提议。
- **已否定**：后来的出图证明这条不成立。

## 格式

```
### R001 一句话写清现象
- 状态：待观察
- 适用模型：gpt-image-2.5-sunburst（换模型后只作参考）
- 现象：实际看到了什么，不写猜测
- 证据：日期，出图文件夹和文件名，样本数，来源（Codex 目检 / 用户反馈原话）
- 可能的原因：（猜测，没有证据时写"不确定"）
- 对出图的影响：下次配对和出图时具体怎么做；关联的提示词经验编号（比如 圣诞珍珠画01 L008）
- 对应的 SKILL.md 规则：写了哪一节，或"还没有"
```
